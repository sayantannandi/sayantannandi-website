# The Optional Career: MailerLite restart pack

[Download the HTML pack](Step_Up_MailerLite_Pack.zip?raw=true)

Extract the ZIP and open START-HERE.html. The pack contains 36 email HTML files: twelve long essays, twelve alternative customer versions, and twelve entry/report/campaign/onboarding emails. It also contains twelve SVG illustrations, an illustration gallery with optional PNG export, plain-text essay copies and a step-by-step setup guide.

Each essay contains 1,015 to 1,063 words before the course section. The course and cohort remain six weeks; the newsletter series runs for twelve weeks.

[Read the setup guide](SETUP-GUIDE.md). [Review the essays](essays-for-review.md). [Website connection contract](website-connection-contract.md).

All sending is designed for MailerLite. No automation or campaign was activated. No subscriber was added or changed. The website-to-MailerLite report connection and verified buyer mapping remain implementation steps. Replace the postal-address marker and populate the report/access fields before sending.

Email visuals are built into the HTML so they remain readable with images blocked. The editable SVGs are separate optional assets, not external dependencies of the email files. The gallery exports PNGs for upload to MailerLite File manager.

The package has programmatic HTML/word-count and ZIP-integrity checks. No rendered inbox test was available; the guide includes the remaining controlled checks.

This directory contains review materials only. Main has not been changed.
