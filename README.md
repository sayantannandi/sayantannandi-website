# sayantannandi.com

Static HTML/CSS/JS site designed for Netlify. No build process or dependencies are required.

## Deploy

1. Push all files in this folder to the root of a GitHub repository.
2. In Netlify, import the repository as a new site.
3. Build command: leave blank.
4. Publish directory: `.`
5. Add `sayantannandi.com` as the production domain and follow Netlify's DNS prompts.

## Key assets

- `/assets/images/home-framework.webp` — homepage framework/banner
- `/assets/images/sayantan-portrait.webp` — About page portrait
- `/assets/style.css` — complete visual system
- `/assets/site.js` — calculator, diagnostic scoring and mobile navigation

The newsletter/contact forms use Netlify Forms markup.
